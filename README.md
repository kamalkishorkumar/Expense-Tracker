# Expense-Tracker
The Expense Tracker is a web application designed to help users manage their finances. It allows users to log income and expenses, categorize transactions, and view a summary of their financial activities. The application is built using HTML, CSS, and JavaScript and is designed to be user-friendly, visually appealing, and responsive across devices.

Features
User Interface:

Simple and intuitive interface with separate sections for income and expenses.
Input fields for date, description, category, and amount of transactions.
Buttons for adding and deleting transactions.
Transaction Management:

Add income and expense transactions separately.
Categorize transactions (e.g., Food, Transportation, Entertainment).
View a detailed list of transactions with category labels.
Financial Calculations:

Calculate total income and total expenses.
Display net income (Total Income - Total Expenses).
Styling and Responsiveness:

Styled using CSS for a visually appealing experience.
Responsive design ensures compatibility with desktops, tablets, and mobiles.
Validation:

Input validation to ensure correct and complete data entry.
Error messages for invalid inputs.
